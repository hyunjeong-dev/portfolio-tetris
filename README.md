# Tetris

## 1. 프로젝트 소개

Unity 6와 URP 2D로 제작한 모바일 테트리스 프로젝트입니다. 
게임 진행, 보드 판정, 블록 제어, 입력과 화면 표현을 책임별 모듈로 분리하고 상태 흐름을 중심으로 구성했습니다.

## 2. 개발 환경

| 항목 | 내용 |
| --- | --- |
| Unity Version | 6000.3.13f1 |
| Language | C# |

## 3. 사용 기술

| 기술 | 사용 목적 |
| --- | --- |
| URP 2D | 2D 게임 화면 렌더링 |
| UniTask | 게임 진행과 라인 제거의 비동기 순서 제어 |
| DOTween | 라인 제거 셀 연출 |
| Input System · UGUI | 키보드 및 모바일 UI 입력, HUD 구성 |
| `ObjectPool<T>` | 고정 셀 `SpriteRenderer` 재사용 |
| ScriptableObject | 보드 크기와 낙하 속도 등 게임 설정 관리 |

## 4. 구현 기능

* 테트리스 블록 조작
    * 7종 블록 스폰 및 좌우 이동, 회전, 소프트 드롭, 하드 드롭
* 플레이 보조 기능
    * 블록이 착지할 위치를 보여주는 고스트 블록과 다음 블록 미리보기
* 보드 및 라인 처리
    * 블록 충돌 판정과 고정, 완성된 다중 라인 제거 및 제거 후 보드 재정렬
* 점수 및 난이도
    * 제거한 라인에 따른 점수와 레벨 계산
    * 레벨에 따른 자동 낙하 속도 조절
* 게임 상태 관리
    * 게임 시작, 일시정지, 게임 오버, 재시작 상태 흐름 처리
* 모바일 해상도 대응
    * 모바일 디바이스의 Safe Area 대응
* 오브젝트 풀링
    * 고정된 블록 셀을 Unity ObjectPool<T> 기반으로 재사용
