# Tetris

## 1. 프로젝트 소개

2D 테트리스 포트폴리오 프로젝트입니다.
내려오는 블록을 이동·회전해 라인을 완성하고, 점수와 레벨을 올리는 게임입니다. 

## 2. 개발 환경

| 항목 | 내용 |
| --- | --- |
| Unity Version | 6000.3.13f1 |
| Language | C# |

## 3. 사용 기술

| 기술 | 사용 목적 |
| --- | --- |
| URP 2D | 2D 게임 화면 렌더링 |
| UniTask | 게임 진행과 라인 제거의 비동기 순서 제어 |
| DOTween | 라인 제거 셀 연출 |
| Input System · UGUI | 키보드 및 모바일 UI 입력, HUD 구성 |
| `ObjectPool<T>` | 고정 셀 `SpriteRenderer` 재사용 |
| ScriptableObject | 보드 크기와 낙하 속도 등 게임 설정 관리 |

## 4. 구현 기능
- **게임 아키텍처**: `Context / Module` 구조로 데이터, 보드, 블록, 입력, UI, 화면 표현을 분리하고 상태 머신으로 게임 흐름을 관리했습니다.
- **블록 조작**: I, J, L, O, S, Z, T의 7종 블록에 대해 좌우 이동, 회전, Soft Drop, Hard Drop을 구현했습니다.
- **모바일 입력**: 화면 버튼의 조작 요청을 입력 모듈로 연결하고, 플레이 가능한 상태에서만 블록을 제어하도록 처리했습니다.
- **Ghost Block**: 현재 블록의 예상 착지 위치를 반투명하게 표시하며, Hard Drop과 같은 착지 위치 계산을 사용합니다.
- **라인 제거 및 점수**: 완성 라인을 판정하고 제거 연출 후 보드를 압축합니다. 제거한 라인에 따라 점수와 레벨, 낙하 속도가 갱신됩니다.
- **일시정지 · 게임오버 · 재시작**: 상태 전환으로 입력과 낙하를 제어하고, 스폰 실패 또는 상단 고정 조건에서 게임오버를 처리합니다.
- **비동기 흐름 관리**: UniTask와 취소 토큰으로 자동 낙하 및 라인 제거 연출의 수명을 관리해 재시작·종료 시 안전하게 정리합니다.
- **연출 및 최적화**: DOTween으로 라인 flash/fade 연출을 적용하고, 고정 셀은 `ObjectPool<SpriteRenderer>`로 재사용합니다.
